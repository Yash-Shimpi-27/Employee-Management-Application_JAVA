# Employee-Management-Application_JAVA

#  Employee Management System in Java

A simple console-based **Employee Management System** built using **Core Java**.  
This project demonstrates the use of **OOP concepts** such as classes, objects, encapsulation, and methods.

---

##  Features

-  Add new employee details  
-  View existing employee records  
-  Delete or update employee data (if applicable)  
-  Data stored in memory (no database required)  
-  Demonstrates object-oriented programming principles  

---

## Technologies Used

- **Language:** Java  
- **IDE (optional):** VS Code / IntelliJ IDEA / Eclipse  
- **Concepts Used:** Classes, Objects, ArrayList, Encapsulation, Methods  

---

## How to Run

1. Clone this repository or download the files.
2. Open a terminal in the project directory.
3. Compile all Java files:
   ```bash
   javac *.java
